# 小规模验收矩阵与覆盖

## 已发布与本批边界

alpha.7已发布一只真实公开发行悦龙科技920188的八字段核验与档案回放。当前批次扩展的是同一发行的预算情形和教学失败案例，不新增真实发行数量，不把例子数记为真实案例数。

```bash
python bjx.py sample-validation examples/sample-validation.json --out-dir local-data/validation-01
```

| 情形 | 可核验资料 | 本批结果 | 真实缺口 |
|---|---|---|---|
| 无比例整手 | 悦龙官方发行参数与已公布配售率 | 假设300万元预算，比例部分0股 | 余股及真实个人最终零获配未知 |
| 跨整手阶梯 | 同一公开发行 | 假设450万元预算为100股、1000万元为200股 | 不是不同发行或真实账户结果 |
| 余股差异 | 公告排序规则，未取得个人数据 | 额外100股仅条件情景，无概率 | 未观察到公开可验证的实际个人差异 |
| 多发行撞资 | 悦龙假设预算/到账与另一只教学发行 | 公告退款同日先投入后释放，600万元教学申购产生5999288元缺口 | 第二只、到账顺序不是已核真实记录 |

退款日是公告字段，退款可用日另行假设；上市日不自动当卖出或回款日。所有回放标历史重建，不加入事前预测成绩。账户验收暂停，不能为了补空白请求账户截图或交易记录。

## 版本与当前有效覆盖

public-sample结果记录engine_version、input_sha256、sample_version、发行公告规则定位与effective_coverage。方法版本、输入、发行规则和保存字段版本分开，不靠发行标签证明所有来源仍可用。

目前覆盖一只历史发行及八项选定原值。离线运行只复用保存核验记录；带本地原文重查才显示精确摘要/选定文本匹配。并未实时检查所有原文、更正或全市场接口，不宣称全年覆盖或市场竞争数量。

下一步优先另一只公开历史发行及更正/边界案例，继续保留找不到的真实零股、余股和资金可用证据缺口。无新中签模型、全年回放承诺或新仓库。与主工作台协作仅经workbench-contract.md契约，不修改其正在维护的代码。
