# 路线与验收

更新日期：2026-10-09。当前功能发行为 v0.2.0-alpha.8；阶段历史不是当前缺口清单。

## 已实现

单发行情景、显式多发行/回购现金账、同本金同期间对照、证据包、原文匹配及版本线索、2026 官方计划日历、假设冻结/事后复盘、一只公开发行八字段、教学边界矩阵及 v1.0 计算接口。覆盖与限制见 [验收矩阵](sample-validation.md)和 [公开样本](public-sample-920188.md)。

## 进行中

继续公开发行样本与更正证据闭环；主工作台接入只经 [版本契约](workbench-contract.md)，双方跨实现等价尚未完成。真实账户验收已由用户暂停，不自动恢复，也不反复索要账户资料。

## 后续

- 年度回放：先取得完整发行区间、来源版本及可得时点；比例部分、未知余股、事后回放与事前快照分别统计。当前没有完整年度库或账户全年收益。
- 同行估值：指定同行池、发行 PE 利润口径及同日估值，不混用不同利润、分类或日期；缺口阻断排名。
- 上市后流动性：限定公开行情的 1/5/20 交易日成交额与换手，缺失单列，不输出未验证卖点。
- 预测与优化研究：仅在证据充分、事前冻结、滚动样本外和独立留出验证后讨论；保留失败结果，未证实改善不发布最优金额或预测能力。

不新增全市场资金池、自动交易或后台行情刷新承诺。现有每周开发任务与应用后台行情服务不是同一能力。
