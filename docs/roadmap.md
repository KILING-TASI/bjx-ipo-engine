# 路线与验收

## v0.1：情景测算（已交付）

显式输入、比例整手、联合情景、费用、两段本金占用、输入校验和教学例。验证边界含零整手仍付成本、最低佣金、精确百股边界、无权重不报告概率、非法输入拒绝。

## v0.2：发行事实与现金账（预览阶段）

公告原文逐字段出处、规则版本、冲突保留；独立联网适配器，失败不填假数据。用户账户多只事件现金账、同日到账顺序、市场交易日历和逐笔回购对照。验收需人工核验发行公告、退款与券商现金记录，不以接口成功替代核验。

v0.2.0-alpha.1已交付：离线事实候选登记、同日现金冲突检查、获配本金留存、回购本金/利息现金事件、显式日历覆盖及实际交收日计息。尚未交付：联网公告适配器、已核验官方日历、真实账户账单验收、两方案同期间汇总对照。预览版的计算检查不等于完整v0.2验收。

v0.2.0-alpha.2补入research-workbench优势：主动来源字节保存与摘要、候选原文绑定、更正标题线索及PDF提取差异、统一研究包与独立发布检查。自动发行字段解析、官方日历、真实账户验收和同期间现金对照仍待完成，不将来源下载称为字段核验。

v0.2.0-alpha.3完成声明现金计划的同本金、同期间对照，含费用、精确小数、占用资金日以及未结清/撞资拒绝比较。示例仍是教学输入；官方日历、真实券商案例和自动发行字段解析尚未验收。

v0.2.0-alpha.4已核对2026官方假期排期与周规则，提供带来源的计划交易日历；不认证实际临时开停市或到账。真实账户验收自2026-10-09按用户要求暂停，不自动恢复，不请求账户材料。后续继续公开发行字段与公共样本研究，账户暂停不阻断这些工作。

## v0.3：年度回放（规划）

完整逐只发行样本与期间，比例部分与余股结果分别记录。历史实际配售和收益为事后回放，不能称事前预测。输出账户累计收益、资金日、现金对照差额和来源覆盖缺口。

## v0.4：预测与优化研究（规划）

预先冻结特征发布时间、目标、基准、损失函数与试验停止条件。按时间滚动训练，模型选择仅在训练/验证窗口完成，最终留出样本独立评估；多策略选择报告校正后的不确定性。右尾覆盖率、概率校准、金额约束与机会成本共同验收。若未证实改善，保留负结果，不发布最优金额或卖点能力。

全市场资金潮汐、联合份额模型、分钟线成交和卖出优化需另有真实样本与证据，当前均未实现。不启用后台监控或交易执行。
