# 多发行声明方案比较（主分支，未发行）

日期：2026-10-09。新方法 declared-plan-comparison.1；旧现金账引擎保持 0.2.0-alpha.8。

先供给 2–32 套明确事件方案；可另供最多 5 个发行事件组，枚举至多 32 个子集（包括不投入）。不生成获配率、余股、卖出日期或资金可用日期，不计算无概率的期望，不称确定最优申购。来源、缺口和同日资金顺序沿用现金账。每个发行组必须有独立 instrument 和事件 id；组合保留原始事件，不重写身份。

```text
python -S bjx.py compare-plans examples/compare-plans.json --out-dir local-data/plans-01
python -S bjx.py verify local-data/plans-01
python -S demo.py --out-dir local-data/demo-plans-01
```

输出另存，新目录保护历史结果。输入摘要、事件、方法版本和参考率参数随结果保存。示例为 3 个明确教学方案及 2 个教学发行组的 4 个组合，共 7 个候选；双发行同日投入超预算，停止回放。未结本金不计完整现金利润；获配本金退款后继续占用。排序仅按可完整回放的占用资金天数，不是收益推荐。图表示每个事件后的锁定本金，非完整连续市场行情图。

## 公开机会成本参考边界

[上交所通用质押式回购规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/bond/trading/currency/c/c_20250606_10781048.shtml)计息口径为首次交收日含、到期交收日不含的自然日占款，年基数 365；本轮 2026-10-09 查阅。规则并不提供可成交利率。尚无本轮已核验公开报价，示例 2% 是人为假设，不冒充公开参考率或用户实际替代收益。

参考率须明确数据时点、来源、标的、期限、首次/到期交收、费用口径、适用限制及 assumption/public_reference。public_reference 必须提供 HTTPS 原始来源，但接口不联网认证提交者来源。费用未知必须明确写未知。展示 锁定资金天数×声明年率/365 的毛成本敏感性，不自动扣到现金利润，也不假设所有闲置资金均可按参考报价成交，不计算净替代收益。实际回购收益仍须用明确本金/利息/费用事件单独建方案。报价导入、净费用校验与跨期限适配为剩余范围。

真实公开样本仍只有悦龙科技八字段，教学两个发行不增加真实样本数。真实账户验收继续暂停。原创代码沿用根 MIT；公开数值与来源权利独立。旧静态截图和冻结预览保持原样，新界面用上述 demo 生成。
