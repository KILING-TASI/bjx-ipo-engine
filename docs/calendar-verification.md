直接获取四份官方网站HTML并阅读指定条款。源字节、UTC抓取时间和SHA256保存于本次本地研究包；公开data/bse-2026-schedule.json保存日期、URL、定位与摘要，不附完整原文。网页下载和文字核验分开记录，摘要不是可信时间戳或第三方认证。

## 使用

```bash
python bjx.py calendar data/bse-2026-schedule.json --out-dir local-data/calendar-2026-01
python bjx.py verify local-data/calendar-2026-01
```

result.json可作为现金账或现金方案比较输入中的calendar对象，basis为derived，保留derivation和来源；不是把推导值伪装成原文逐日列表。跨年、超覆盖及非交易日事件仍拒绝。

输入假期是人工核对后保存的日期，构建器只检查来源引用和生成一致性，不自动认证输入的官方真实性。2026日历含晚于年初发布的专项来源，不能用来声称年初已获得全部资料或完成事前预测。

尚未穷尽核对所有临时停市公告，年度实际开市逐日记录未认证；也不据日历推断T+2退款、回购本金或利息到账。真实账户验收自2026-10-09起按用户要求暂停，仅经用户明确恢复后继续。
