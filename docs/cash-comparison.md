# 同本金、同期间现金方案对照

```bash
python bjx.py compare-cash examples/compare-cash.json --out-dir local-data/cash-comparison-01
python bjx.py verify local-data/cash-comparison-01
```

这是一份明确输入的现金事件研究，不是选股、收益预测、账户认证或完整年度回测。输入必须声明teaching、scenario或historical_replay，事后回放不能冒充事前预测。当前只支持人民币。

## 一个共同研究期间，两份现金计划

start、end、initial_cash、calendar在顶层统一声明。两份plans只含id、basis、events，不允许分别更改本金、期间、日历，也不接收预计算收益率或机会成本年率。事件必须全部在共同期间内；日历覆盖不足或事件超出区间时拒绝计算，不静默截断。

期初现金没有已冻结资产或外部融资。期初与期末可以是声明日历覆盖内的非交易日，事件自身必须是声明的交易日。同日到账规则沿用现金账：缺完整顺序依据时，先检查投入和费用，再释放现金。输入日历仍由调用者核验，不因通过日期检查就认证官方日历。

## 结果怎样计算

- 期末可用现金：执行完所有声明事件后的余额；如果计划撞资，期末值留空，只保留已回放余额。
- 已结清现金盈亏：只有全部计划可执行且申购/回购本金均回收，才计算期末现金减期初本金。
- 账户期间现金收益率：上述盈亏除以共同期初现金，不年化，不复利。
- 本金占用资金日：按事件间实际自然日积分留存申购与回购本金。积分区间为[start,end)，期末当天现金事件计入期末余额，没有虚增后续占用天数。
- 第一方案减第二方案差额：仅当两份声明计划均已结清时输出。不自动推荐方案，也不推断差额可持续。

金额以Decimal计算，新增*_exact字符串保存现金账精确小数；原float字段仍保留兼容。比较从精确字段取数，收益率小数按Decimal默认精度28位表示，不是无限精度计算或券商账单舍入规则。

如果任一计划本金未回收，就保留unsettled_principal，不以账面本金估算市场价值或将未回款认定亏损。发生资金冲突就保留cash_conflict，不假定融资、不给部分计划期末收益和资金日估计。

## 费用与现金替代

现有sale事件的amount是扣卖出费用后的净回款。repo_interest可输入已扣费净利息；另付费用用新增fee事件减少现金、不减少留存本金。fee与当日投入一起检查可用现金，不能先花预期退款。

费用已经包含在净回款或净利息时不得再次录入fee；模块无法独立认证实际费用完整性。替代方案目前支持已有回购本金、利息和费用现金事件，不自动填入货基、活期利息、报价、节假日交收或产品收益。

比较不扣机会成本。把“已扣现金替代机会成本的单只净收益”拿来再与现金方案收入相减，会造成重复扣减；此入口拒绝直接输入该预计算结果。利息只按显式到账事件计入，期末尚未到账或未提供的利息不补造，完整性待核验。

## 教学样例与验收限制

样例本金1000元、2026-10-12至10-20：假设申购计划获配本金200元，最终净回款250元，声明现金盈亏50元；现金替代计划人为假设利息5元、另付0.10元费用，盈亏4.90元；差额45.10元。样例不是实际发行、回购报价、历史业绩或推荐。

校验覆盖结清、撞资、未回收本金、全部亏损、日历与区间错配、共同参数覆盖拒绝、重复机会成本输入拒绝、小数费用和研究包绑定。真实券商记录、官方日历与完整v0.2业务验收仍未完成。
