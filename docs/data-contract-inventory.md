# 数据入口与交付边界

本页为当前数据盘点及本批状态的权威入口，2026-10-10。软件行为详见已有专题契约，不维护第二套计算规则。本批只盘点、包装已有公开记录和登记差异；不新增采集服务。原件及私人数据不发布。

## 职责与独立运行

本仓负责北交所发行选定事实、声明情景、现金事件账、计划日历及有限公开回购参考。上游为原发布者与显式输入；下游可选工作台或独立调用者。公司经营、综合研究判断和报告组织留 research-workbench；财报库、基金穿透、MarketLens 与规则库各守其专题边界，本仓不代其扩成估值审计、基金全评价或全部公司事件平台。

最短离线运行：仓库根目录执行 `python -S engine.py examples/scenarios.json`；统一入口及完整可运行示例见 [README](../README.md)。标准库计算无需安装工作台。PDF 原文匹配才需要可选 pypdf；下载必须显式选择在线入口。依赖与许可见 pyproject.toml、[第三方说明](../THIRD_PARTY_NOTICES.md)。

## 有界包装与契约差异

[包装样例](../examples/data-envelope.json) 用 `payload` 原样保存三个本地公开记录，附身份、原文件字节摘要、原 schema、覆盖类型、未知历史可得时间、更正链状态及权利边界。本地 JSON 往返、三 payload 完整相等和原字节摘要已核查；未更改源文件、旧 API、旧冻结结果。它是可选档案设计样例，不是新增计算输入接口或九仓共用标准；直接传给 api.py 不支持，必须明确取回原 payload 并走对应原入口。暂无生产迁移器。

原专业字段、时间精度和状态留在 payload；不强制日频或共用状态枚举。源数据无 schema 时明确标未版本化，不伪造版本。取得时间不是历史可得时间；null 配明确 unknown 状态，不填零。

反例：公告退款日期不可变成账号到账事实；定盘百分数不可当 fraction 直接计算；计划交易日不可当实际开市认证；下载成功不可当语义核验；当前取得快照不可用于证明当时预测可得；冲突来源不可选“最新”自动覆盖事实。原生接口可能忽略部分额外字段，跨仓严格桥接明确拒绝融资、滑点及年度字段，不能声称二者完全等价。

重复入口：capture 保存原件、public-sample 核选字段、回购入口核选定盘、vendor 比较版本都有摘要处理，但职责不同；可复用同一原始快照，不能省略各自语义核验。基金净值/分红拆分与宏观修订序列没有本仓入口或样本；行情仅单条定盘参考，无日线数据库。四条优先链目前仅公告与计划日历相关部分已盘点。

## 本批结案点与后置项

本批交付为入口目录、契约差异、三个无损包装样例、版本/交付边界以及链接检查，沿用 PR #1；最终提交与检查记录在 [开发记录](progress.md)。完成这些即结案，不以 idle 表示完成，也不继续叠加采集或大重构。

后置项：与已有专业任务核验同一公开记录的读取语义并确定共用结构；完成后再决定是否生产化适配器。更正链闭环、第二发行、年度回放和滚动样本外预测按 [路线](roadmap.md) 后续推进。无全市场采集、新仓库、后台服务、自动安装、合并或新版本发布。
