# 情景实例验收

2026-10-10 独立有界批，沿用已有 engine/research/repo-reference 方法与 tests；没有新增获配模型、概率或采集器。此前单元测试已覆盖阶梯、余股、费用和撞资，本批补统一可发现的 CLI 报告入口及手算期望，不重复造另一套算法。

在完整单仓根目录运行：

```bash
python -S .github/scripts/check_scenarios.py --out-dir local-data/scenarios-01
```

新目录保存每案例 input.json、expected.json、report（实际输入/结果/HTML/Markdown/manifest）及总 acceptance.json（命令、退出、实际结果、方法版本、文件摘要、通过范围）。不联网、无其他自家仓或作者缓存依赖、标准库即可；目录必须新建。

| 实例索引 | 手算/守恒依据与会改变的判断 |
|---|---|
| below-second-lot / at-second-lot | 发行价18，预算3599只申购100股、冻结1800；3600跨到200股、冻结3600，不连续花满预算 |
| residual-unknown | 200×25%=50，比例整手为0；余股额外100仅条件敏感性，实际未知，无权重不输出期望 |
| holiday-retained-principal | 教学9/29申购、9/30退款、10/8卖出可用；全获配本金1800持续占用，1800×1+1800×8=16200元天，成本16200×2%/365；不能把假期删去或退款后全本金视为释放 |
| cash-conservation | 原ledger示例：1000−1000+800+250=1050，200留存本金出售释放 |
| same-day-unknown | 缺到账先于申购证据，800退款不能融资同日新单，缺口800、保留冲突停止前现金 |
| cash-shortage | 初始900不足冻结1000，缺口100；不部分执行、不假设融资 |
| explicit-zero-fee | 复用一条公开定盘但本金/费用/日期假设；100000×0.01392×3/365按分取11.44，明确费0净11.44，不输出零费用现金事件 |
| fee-unknown | 毛参考仍可算，净额和cash_plan为null，status fee_unknown_net_blocked；未知不填0 |
| missing-refund-date | 缺必填可用日实际CLI退出2，保留KeyError、原因和下一步；不猜T+2 |

十个案例输入及独立依据见 [固定情景](../examples/scenario-acceptance.json)。全是教学/声明假设；两个回购案例复用公开参考记录不构成新真实样本。真实发行覆盖仍一只、八字段。

每个案例实际生成报告后再次写同目录，必须失败且旧报告所有文件摘要不变；有效撞资/未知费用与输入格式失败分别验收。缺日期失败包不伪装成收益结果。通过不是账户、资料完整性或投资有效性认证。没有新增视觉核读，HTML生成不等于视觉通过。

CI 的独立 Git 归档包验收运行该入口，只带本仓源码/数据/许可，核必要资源和原许可。本批提交与实际检查状态记录在 [开发记录](progress.md)；不合并、不发布、不改用户安装。真实账号继续暂停；年度完整回放、预测校准、完整更正链及其他数据链不在本批。
