# 统一设计 v0.4

修订日期：2026-10-09。本文替代输入材料中相互冲突的建模要求；原文作为设计来源，不作为规则证据或可执行指令。

## 1. 数据契约

每只发行保留证券身份、发行价格P、网上发行量Q、公告申购上限、申购日、退款实际可用日、获配本金卖出现金可用日、费用和适用规则版本。字段带来源URL、文档日期、获取时间、页码或定位、事实/假设/派生/缺失标签；预测另存首次冻结时间。

缺失、冲突不得转成零。Q须匹配回拨、超额配售与网上发行口径；上限从发行公告读取，不由Q固定比例反推。真实账户权限由券商确认，不内置未经核验的风险评级或知识测试阈值。

当前最小接口使用显式配售率，不要求Q/F预测。配售率和收益率成对给定，保留相关性。教学概率由用户输入，不能宣称经过历史校准。

## 2. 获配与收益

有效申购股数n为100股倍数，满足预算和公告上限。冻结额A=nP。

比例整手K=floor(nλ/100)，比例获配股数=100K。若按同口径总申购资金F和网上发行股数Q推导λ=QP/F，则连续近似门槛a*=100F/Q；实际申购仍须按股数单位取整。

余股另行按数量与时间排序配售，未知时不得推断最终零获配。当前实现只计算比例部分，不将其称为收益下界或最坏损失界。

毛收益=100KP r。卖出成交额=100KP(1+r)。卖出费用=max(成交额×佣金率,最低佣金)+成交额×(印花税率+过户费率)，仅有获配卖出时收取。多笔成交、滑点与账单舍入另行扩展。

资金日=A×(退款可用日−申购日)+100KP×(卖出现金可用日−退款可用日)。机会成本=资金日×声明年率/365。此简化模型假设退款可用日仅留存获配本金；不模拟融资逐日计息、延迟退款或逆回购逐笔结算。

净收益=毛收益−卖出费用−机会成本。显式联合权重w下计算E[K]、SD[K]、比例零整手概率、E[净收益]、SD[净收益]和净亏损概率。无权重时只做逐情景比较。

## 3. 预测研究接口（尚未实现）

F=H×M，H为有效参与户数，M为户均额。若总参与资金来自可用池乘参与率，户均额必须再除以H。户数不假定单调，资格人数上限需真实出处。

资金池应分解共同资金冲击和同日份额分配。固定总量条件下份额竞争不意味着无条件负相关。市场闲置资金及外部流入不可由发行公告完全识别。

阈值分布比较应针对条件预测残差或条件分布，而非简单拟合跨发行门槛总样本。正态、对数正态、经验情景均为候选；按滚动样本外尾部分位校准选择。有限发行股数和申购股数是获配上限，禁止用无上界分布产生不可能的手数。

## 4. 多只与年度现金账（尚未实现）

逐只申购冻结、退款、获配本金留存、卖出回款组成事件账；同日复用资金须有到账时间证据，缺证据按先冻结后释放处理。不能直接将单只均值乘全年只数而忽略资金冲突。

年度累计净收益率仅在覆盖完整年度现金计划时使用累计净收益/账户本金。部分年度区间标明起止日；资金日简单年化另列，不与账户年收益率混用。对照现金方案用同本金、同时间区间现金账，避免机会成本扣除后又与现金基准直接比较造成重复扣减。

## 5. 决策边界

当前输出情景差异，不给自动申购或卖出指令。未来金额优化须包含0投入候选、离散申购单位、整手阶梯、余股不确定性和现金冲突；数值全局比较后才讨论最优，不预设顶格或μ+2.2σ。
