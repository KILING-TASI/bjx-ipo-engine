# 盈亏平衡和余股敏感性

v0.2.0-alpha.5补充解释，不新增预测或申购推荐。原有概率汇总仍只包含比例整手，不含未知余股。

## 盈亏平衡卖出涨幅

固定本次获配股数、申购冻结额、资金占用日期和费用，求净收益为零的卖出涨幅。卖出费用中的佣金取max(比例佣金,最低佣金)，因此分别求解最低佣金与比例佣金分支，不把两项同时相加。

比例整手为零时不输出盈亏平衡涨幅，因为改变卖出涨幅无法弥补没有股票卖出的资金占用。总比例卖出费率达到100%时拒绝计算，避免没有有限平衡点却输出数字。

该阈值不是上市价格预测、保证收益或最优申购金额。费用与时间变化会改变它；分批成交、滑点及实际账单舍入仍未建模。

## 额外百股条件情景

在比例配售存在零头且申购股数足够时，另算假设余股排序获配100股后的总毛收益、卖出费用、留存本金占用、净收益与平衡涨幅。冻结额不增加，但更多本金留存到卖出现金可用日。

该情景不赋予概率，不加入原加权期望，也不是上下界或最坏损失界。低涨幅或破发时，多获配可能扩大损失。无比例零头或没有申购时，不凭空添加余股敏感性。

## 教学例

本金1000万元、预算800万元、发行价18元、资金成本年率2%，均为假设。中配售情景比例获配100股时，盈亏平衡涨幅约49.09%；高配售情景200股时约24.59%。低配售情景若卖出涨幅为-20%，假设额外获配100股会使声明净损失由876.62元增加至1242.95元。

这些数字仅解释给定输入的成本与阶梯，不代表真实发行、余股排序结果或未来收益。报告并列输入假设、基础成本拆解、平衡点、敏感性与风险。HTML表格所有单元格转义，内容结构检查不认证完整视觉排版。
