# 对四份输入材料的修订

输入来源：北交所打新决策引擎-设计方案、扩展设计详解、硬核补丁v0.3、收益测算模块-设计方案。原文件未附入仓库，以下保留问题和替代口径。

| 原表述或冲突 | 修订 |
|---|---|
| 门槛以下期望为零，直接拒绝 | 随机门槛下可能非零，余股更使最终获配未知；不能用均值作硬拒绝线 |
| 25%概率不中，随后写成一半概率 | 统一概率定义；比例部分与最终获配分开 |
| 最低佣金=比例佣金+5元 | 应为max(比例佣金,最低佣金)，且只在成交时计 |
| 首日涨幅与获配手数近似独立 | 使用成对联合情景；破发与拥挤可能相关 |
| 单只净收益随金额单调增、顶格必优 | 阶梯收益和线性成本产生局部下降，应数值比较候选金额和0投入 |
| 报童公式、二元模型和多手模型混用 | 二元模型内部驻点为Gf(A)=κ，仍须比较边界与0；不能当完整多手全局解 |
| 用单个主导阶梯推导A_crit | 多阶梯共同贡献，近似不作为生产判定或收益保证 |
| 正态阈值无限求和或固定30档 | 正态在零附近的密度使无界逆阈值期望有发散问题；必须使用真实股数上限或有限情景 |
| 固定总池意味着同日F必负相关 | 只是条件竞争；共同资金冲击可能使无条件相关为正 |
| 日历可确定全网资金供给 | 只可核验已知冻结事件，闲置资金、外部流入与参与率需估计 |
| 户均额=资金池×参与率 | 此式为总额，户均额须除以参与户数 |
| 周末成本结论与逆回购d_eff表相冲突 | 自然日现金成本与逐笔回购替代现金账分别建模，不逐日叠加不可同时持有的回购 |
| 只算退款之前的资金成本 | 获配本金继续计到卖出现金可用日；融资/机会成本避免重复计 |
| 总股数、冻结资金、配售率随意拼用 | 相同发行及相同网上口径才可交叉派生，百分数与小数单位显式声明 |
| 全年均值×只数代表可实现年收益 | 首先通过逐只资金账和现金冲突检查，部分年度与全年分开 |
| 2026年65只、收益速算表为实测 | 未取得逐项原始出处；从默认参数和真实业绩描述中删除 |
| 最佳策略超过基准2个标准误即验收 | 同样本选策略会产生选择偏差；预注册、嵌套选择及独立留出测试 |

结果：首版缩为可审计的情景内核；预测、资金排程和卖出优化保留独立接口与验收要求，不以设计稿替代验证结果。
